# 第1章 情绪地图

## 读者进入这章时的状态
读者从"走。去三号码头。"这个悬念钩子返回（如果之前读过），或是全新开始。无论哪种，都需要从林战出狱的迷茫切入——一个坐过三年牢的年轻人，面对陌生的城市，身无分文，前途未卜。读者应该感受到那种**被世界抛下的窒息感**，同时好奇：系统是什么？玉佩从哪来？他接下来怎么办？

## 这章的情绪弧线
**压抑 → 希望 → 紧张 → 温暖 → 沉重 → 紧迫**

- 开头压抑：出狱后的格格不入，社会的冷漠，经济的困窘
- 中段希望：系统觉醒带来转机，发现自身能力
- 随即紧张：公交车偶遇张强，仇人相见，冲突一触即发
- 短暂温暖：老周的善意，父亲旧交的情谊，第一桶金
- 再度沉重：陈氏医院的线索意味着更大的麻烦，王大力的话题暗示地下世界
- 结尾紧迫：系统突然预警，青梅竹马的母亲中毒，倒计时2小时——必须立刻行动，前往三号码头

读者从这章出去时，应该带着两个疑问：**① 苏晴母亲能不能救？② 三号码头有什么？**

## 关键场景（3个）

### 场景一：出狱与觉醒
**作用**：建立主角初始状态 + 金手指出现。让读者知道林战是谁、他失去了什么、他有什么新能力。

**发生了什么**：
林战踏出监狱大门，阳光刺眼。没有接他的人，只有口袋里皱巴巴的释放证明和一块撞破一角的碎玉佩（父亲入狱前留下的信物）。他在公交站等车，司机看到他穿的衣服（旧 prison 制服改的）油门踩得更快。手机是老人机，余额3.2元。这时玉佩突然发烫，脑海响起机械音：「医武双修系统绑定成功。宿主：林战。境界：武道淬体一层（0/100），医道入门（0/100）。」系统界面展开，有诊断、针灸、任务、商城四个板块。第一个新手任务弹出：「完成一次精准诊断（0/1）」。林战站在街角，指节捏得发白——这操蛋的人生，终于有了一线曙光。

**过渡到下一场景**：
他顺着系统指引走向22路公交站，想着先找个便宜旅馆安顿。就在这时，他看见了一个熟悉的身影——张强，正从一辆商务车上下来，和司机说笑。林战立刻贴在电线杆后，瞳孔微缩。三年前，就是这家伙做伪证，把他送进监狱。

### 场景二：公交车打脸
**作用**：第一个爽点。展示系统能力，立威，让读者知道"主角不是好惹的"。

**发生了什么**：
22路公交车进站，林战混在人群里上车。张强坐在后排玩手机，没注意到他。林战靠近，启动系统扫描——【目标：张强，28岁。健康状况：腰椎间盘突出（重度），膝盖旧伤，肾虚】。他冷笑，这正是当年张强诬陷他时，他私下查到的隐疾。

林战在张强对面坐下，低声说："张主管，别来无恙。"张强抬头，脸色瞬间煞白。"你…你怎么…""腰椎L4-L5突出，膝盖半月板撕裂，还有肾虚——这三样，够你在床上躺三个月。"林战手指在手机边缘划过，"需要我把你当年怎么举报我，又怎么篡改监控的事，发给陈绍文吗？"张强嘴唇发抖，死死盯着他。林战凑近，声音更轻："滚。再让我看见你，下次就不是警告了。"公交车到站，张强几乎是跌跌撞撞冲下车，手机掉在车上都没敢回头捡。

全车寂静。林战坐回座位，心跳平稳——系统提示：「完成首次诊断，奖励医道经验+10，武道经验+5」。他看向窗外，陈氏集团大楼在远处矗立。这才刚开始。

**过渡到下一场景**：
公交车到站，林战下车，漫无目的走着。他需要钱，需要住处，需要知道这个世界现在是什么样子。这时他想起父亲入狱前提过的一个名字：老周。仁心诊所。横街。他拦了辆出租车，报上地址。

### 场景三（爽点/高潮）：老周与初始资源
**作用**：获得第一笔启动资金 + 关键线索 + 第一个盟友。从个人复仇转向更大的棋盘。

**发生了什么**：
仁心诊所在老城区横街深处，门脸很小，招牌漆皮剥落。林战推门进去，药香扑面。柜台后坐着个五十多岁的男人，头发花白，穿白大褂，正在看医书。"哪位？"男人抬头，眼神锐利。林战没立刻答，而是从脖子上取下那块碎玉佩——只剩一角，但纹路清晰。老周的手抖了一下，眼镜滑到鼻尖。"你是…国栋的儿子？"他声音低了下去。

老周煮了茶，听林战说完这三年。他从保险柜取出一个牛皮纸袋：「你爸三年前托我保管的。他说如果你出来，就交给你。」里面是1000元现金，和一份复印件——陈氏医院进口药走私账目，涉及金额数千万。老周说：「你爸当年就是查这个，才被陈绍文盯上。」他顿了顿：「战哥，我现在只是个开小诊所的，帮不了你太多。但这1000块，你先拿着安顿。南江这潭水，深着呢。」

林战捏着纸袋，喉结滚动。他没问父亲现在在哪——问了也是徒劳。他深深鞠了一躬："谢谢周叔。"

临走时，老周叫住他："东三条巷，老铁修车铺，王大力。你狱中那个兄弟，他一直在找你。去他那住吧，安全。"

**余韵**：
林战走出诊所，夜风凉。他捏着1000元，掌心出汗。这笔钱够他撑一个月，但远远不够。陈氏医院的线索像一把双刃剑——能扳倒仇人，也能要他的命。王大力的存在让他心头一暖，可老周那句"南江水深"又让他后背发凉。他站在街口，看着远处陈氏集团大厦的灯光，突然觉得这城市像一头蛰伏的巨兽。

## 结尾钩子
**类型**：危机 + 倒计时

**感受**：读者刚松一口气（资源到手，盟友在望），系统突然炸响紧急警报。那种"麻烦自己找上门"的无力感和紧迫感——**你还没去找仇人，仇人的刀已经架在你在乎的人脖子上**。读者会疯狂翻页：苏晴是谁？她母亲怎么了？三号码头有什么？林战来得及吗？

**具体表现**：
林战刚走出仁心诊所，手机震动（是系统界面弹出红色警告）。【紧急任务：苏晴母亲中毒，症状：剧烈腹痛、呕吐、意识模糊。剩余时间：1小时58分。地点：三号码头仓库区B座3号】。他脑子里轰一声——苏晴，那个他出狱前唯一联系过的女孩，他欠她太多。定位显示三号码头在南江区最乱的码头，蛇头帮的地盘。

他咬牙，拦了辆出租车："去东三条巷，老铁修车铺。开快点。"

**最后一句定格**：
车窗外霓虹闪烁，林战握紧口袋里的碎玉佩。系统倒计时在他视网膜上跳动：01:55:23。
"走。"他低声说，"去三号码头。"

## 写手注意事项
1. **情绪连贯**：三个场景的情绪要像河流——出狱的压抑 → 系统觉醒的微光 → 公交车打脸的肾上腺素飙升 → 老周带来的温暖与沉重 → 最后被系统预警掐断。**不要让情绪断层**，用环境和身体细节过渡（如林战握玉佩的手、公交车玻璃上的倒影、老周茶杯的热气）。

2. **克制描写**：按风格D，不要直接写"林战很愤怒"，写他的动作——"指节捏得发白""喉结滚动""瞳孔微缩"。对话要短，留白比说尽更有力。

3. **伏笔回收**：
   - 张强的恐惧要在公交车场景后立刻体现（他下车时手机掉了没敢捡）
   - 老周的"南江水深"要成为后续剧情提示
   - 王大力的修车铺要在本章提及但不能出现（为第2章铺垫）
   - 蛇头帮的名字要提，但不要解释（悬念）

4. **字数分配**（共约2000-2200字）：
   - 场景一（出狱觉醒）：500字
   - 场景二（公交车打脸）：700字 **（核心爽点，写细）**
   - 场景三（老周诊所）：600字
   - 结尾预警+钩子：200字

5. **系统界面**：不要大段文字弹窗，用碎片化提示——扫描时「目标：张强…」一行小字，诊断完成「奖励+10」一闪而过。系统是工具，不是解说员。

6. **时代感**：现代都市，但不要写具体年份。手机用"老人机"，转账用微信（老周给现金是刻意为之——现金不留痕）。
